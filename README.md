### Daily Quote & Mood Journal

A beautiful, lightweight, single-page web application designed to help users track their daily emotional well-being and stay inspired. This project was built entirely using AI assistance and is hosted directly via GitHub Pages. 

### Features

* Mood Tracking: Quick buttons to log your daily mood (Happy, Calm, Focused, Stressed).
* Journaling: A dedicated workspace to write down your thoughts and daily reflections.
* Local Storage: Automatically saves entries directly to your browser so your data stays private and secure.
* Daily Inspiration: Generates uplifting quotes to kickstart your day.
* Responsive Design: Works perfectly on both desktop monitors and mobile screens.

### Tech Stack

* HTML5: Structuring the journal interface.
* CSS3: Clean, modern, and user-friendly styling.
* JavaScript (ES6+): Handling mood logging, quote generation, and localStorage management.
